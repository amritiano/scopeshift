# ScopeShift

Delivery leads at small implementation agencies need to understand the consequences of a client request before promising a date or price. ScopeShift turns a request into a documented trade-off against an immutable approved scope.

The decision path is: define baseline, request change, estimate effort, calculate feasible schedules, compare responses, select an exact proposal revision, approve or reject, apply atomically, retain history.

Team members contribute requests and scenario estimates. Leads manage baselines and proposals. Explicitly shared clients request and approve changes without seeing internal labor costs. Every demo client and person is fictional.

Success hypotheses, not measured outcomes: less unapproved work, faster proposal decisions, fewer ambiguous commitments. No interviews or customer results are claimed.
